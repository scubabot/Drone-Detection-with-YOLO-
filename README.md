# Drone-Detection-with-YOLO-
A full end-to-end computer vision pipeline for real-time drone detection. Covers the complete workflow from dataset preparation and model fine-tuning with YOLOv8x, to image and video inference, result transfer, and live camera testing. Deployed on a Jetson Orin Nano with ModalAI VOXL hardware.
